# Student Task Manager 📚

A collaborative C++ project designed to help students efficiently manage, organize, and track their daily academic tasks, assignments, and to-do lists. Developed as part of collaborative coursework.

---

## 🚀 Features

- **Task Management:** Add, view, update, and delete academic tasks seamlessly.
- **Search Functionality:** Quickly search and filter through existing tasks by title or keyword.
- **Data Persistence:** Save and load tasks directly from file storage.
- **Browser History Integration:** Navigate through task management history using custom stack data structures.

---

## 🛠️ Tech Stack & Tools

- **Language:** C++
- **Version Control:** Git & GitHub
- **Development Tools:** Visual Studio Code / Command Prompt
